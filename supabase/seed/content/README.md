# 시딩용 원문에 대하여

`unsu-joheun-nal.txt`는 현진건의 「운수 좋은 날」(1924, 저작권 만료작 — 한국저작권위원회
공유마당에 만료 저작물로 등록되어 있음) 전문입니다. 사용자가 공유마당에서 내려받은
공식 원문 PDF를 전달해 주어, 그 내용을 그대로 옮겨 담았습니다.

원문을 다른 판본으로 교체하고 싶다면 이 파일 내용을 통째로 바꾼 뒤 `npm run seed`를
다시 실행하세요. (문단은 빈 줄로 구분하면 됩니다.) 재시딩 시 기존 `books`/`book_pages`가
중복되지 않도록, seed 스크립트는 같은 제목의 책이 이미 있으면 건너뜁니다. 원문을
교체했다면 Supabase에서 기존 책 행을 지우고 다시 시딩하세요.
