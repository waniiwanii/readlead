# 시딩용 원문에 대하여

`unsu-joheun-nal.txt`는 현진건의 「운수 좋은 날」(1924, 저작권 만료작 — 한국저작권위원회
공유마당에 만료 저작물로 등록되어 있음)의 도입부 일부만 담은 짧은 예시 발췌본입니다.

이 세션에서는 네트워크 정책상 `gongu.copyright.or.kr`, `ko.wikisource.org` 접속이
막혀 있어 공식 원문 파일을 직접 내려받아 대조하지 못했습니다. 따라서:

- 지금 들어있는 텍스트는 앱의 밑줄/낙서/댓글 기능을 시연하기 위한 최소 예시일 뿐,
  전체 작품도 아니고 원문과 한 글자도 다르지 않다는 보장도 없습니다.
- 실제 서비스에 쓰려면 공유마당 작품 상세 페이지
  (`https://gongu.copyright.or.kr` 에서 "운수 좋은 날" 검색 → 만료 저작물 상세 →
  TXT 다운로드)에서 공식 원문을 받아 이 파일 내용을 통째로 교체한 뒤
  `npm run seed`를 다시 실행하세요. (문단은 빈 줄로 구분하면 됩니다.)
- 재시딩 시 기존 `books`/`book_pages`가 중복되지 않도록, seed 스크립트는
  같은 제목의 책이 이미 있으면 건너뜁니다. 원문을 교체했다면 Supabase에서
  기존 책 행을 지우고 다시 시딩하세요.
